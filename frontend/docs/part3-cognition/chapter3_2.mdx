# Chapter 1: NVIDIA Isaac Sim - Photorealistic Simulation and Synthetic Data Generation

## Introduction

NVIDIA Isaac Sim represents a revolutionary approach to robotics simulation, combining the Omniverse platform's photorealistic rendering capabilities with advanced physics simulation and robotics-specific tools. Designed explicitly for AI development in robotics, Isaac Sim enables the generation of synthetic training data with visual fidelity that closely matches real-world conditions. This chapter explores the utilization of Isaac Sim for creating realistic simulation environments and generating the large datasets required for training modern AI systems in robotics applications.

## Explanation

Isaac Sim leverages NVIDIA's Omniverse platform to create physically accurate and visually realistic simulation environments. Unlike traditional simulators that prioritize physics accuracy over visual quality, Isaac Sim achieves both simultaneously, making it ideal for developing perception systems that must operate reliably in real-world conditions. The platform's ability to generate diverse synthetic datasets accelerates AI model development by providing virtually unlimited training scenarios without the constraints of physical data collection.

### Photorealistic Rendering Pipeline

Isaac Sim's rendering system incorporates:
- **RTX Ray Tracing**: Realistic lighting, shadows, and reflections
- **Physically Based Materials**: Accurate surface properties and textures
- **High Dynamic Range (HDR)**: Realistic lighting conditions
- **Global Illumination**: Complex light interactions and indirect lighting

### Synthetic Data Generation

The platform enables:
- **Domain Randomization**: Variation in lighting, textures, and object placement
- **Large-Scale Data Collection**: Automated data generation pipelines
- **Ground Truth Annotations**: Perfect labels for training data
- **Scenario Diversity**: Wide range of environmental conditions

### AI Training Applications

Synthetic data from Isaac Sim supports:
- **Perception Model Training**: Object detection, segmentation, and classification
- **Reinforcement Learning**: Safe environment for robot skill acquisition
- **Sim-to-Real Transfer**: Training models that work in physical environments
- **Edge Case Generation**: Rare scenarios difficult to capture physically

### Integration with Robotics Workflows

Isaac Sim connects with:
- **ROS 2 Bridge**: Standardized communication protocols
- **Isaac ROS Nodes**: Hardware-accelerated perception components
- **Training Pipelines**: Direct integration with AI frameworks
- **Real Robot Calibration**: Simulation-to-reality parameter mapping

import omni
import carb
from omni.isaac.core import World
from omni.isaac.core.utils.stage import add_reference_to_stage
from omni.isaac.core.utils.prims import get_prim_at_path
from omni.isaac.core.objects import DynamicCuboid
from omni.isaac.sensor import Camera
from pxr import Gf, Sdf, UsdGeom
import numpy as np
import cv2
from PIL import Image
import os

class SyntheticDataGenerator:
    def __init__(self):
        # Initialize Isaac Sim world
        self.world = World(stage_units_in_meters=1.0)
        
        # Create base scene
        self.setup_scene()
        
        # Initialize camera for data capture
        self.setup_camera()
        
        self.data_counter = 0
        self.output_dir = "./synthetic_dataset"
        os.makedirs(self.output_dir, exist_ok=True)

    def setup_scene(self):
        """Create a randomized scene for synthetic data generation"""
        # Create ground plane
        ground = self.world.scene.add_default_ground_plane()
        
        # Add various objects with different materials and textures
        objects = []
        
        # Add colored blocks with random positions
        for i in range(5):
            position = [np.random.uniform(-2.0, 2.0), np.random.uniform(-2.0, 2.0), 0.5]
            color = [np.random.uniform(0.1, 1.0), np.random.uniform(0.1, 1.0), np.random.uniform(0.1, 1.0)]
            
            cube = DynamicCuboid(
                prim_path=f"/World/cube_{i}",
                position=position,
                orientation=[0, 0, 0, 1],
                color=color,
                size=0.2,
                mass=0.5
            )
            self.world.scene.add(cube)
            objects.append(cube)

    def setup_camera(self):
        """Setup camera for synthetic data capture"""
        # Add camera prim
        self.camera_prim = add_reference_to_stage(
            usd_path="/Isaac/Props/ArchvizProps/Props/prop_cctv_camera.usd",
            prim_path="/World/Camera"
        )
        
        # Set camera position
        camera_xform = UsdGeom.Xform(self.camera_prim)
        camera_xform.MakeOneXform()
        camera_xform.AddTranslateOp().Set(Gf.Vec3d(2.0, 0.0, 1.5))
        camera_xform.AddRotateXYZOp().Set(Gf.Vec3d(-20, 0, 90))
        
        # Create camera sensor
        self.camera_sensor = Camera(
            prim_path="/World/Camera/Camera",
            position=[0, 0, 0],
            frequency=20,
            resolution=(640, 480)
        )

    def generate_synthetic_data(self, num_samples=100):
        """Generate synthetic RGB and depth data"""
        print(f"Starting synthetic data generation for {num_samples} samples")
        
        for i in range(num_samples):
            # Randomize scene slightly
            self.randomize_scene()
            
            # Step the simulation
            self.world.step(render=True)
            
            # Capture RGB image
            rgb_data = self.camera_sensor.get_rgb()
            if rgb_data is not None:
                rgb_image = Image.fromarray((rgb_data * 255).astype(np.uint8))
                rgb_path = os.path.join(self.output_dir, f"rgb_{self.data_counter:05d}.png")
                rgb_image.save(rgb_path)
                
                # Capture depth data
                depth_data = self.camera_sensor.get_depth()
                if depth_data is not None:
                    depth_image = Image.fromarray((depth_data * 255).astype(np.uint8))
                    depth_path = os.path.join(self.output_dir, f"depth_{self.data_counter:05d}.png")
                    depth_image.save(depth_path)
                    
                    # Generate segmentation data if available
                    try:
                        seg_data = self.camera_sensor.get_semantic_segmentation()
                        if seg_data is not None:
                            seg_image = Image.fromarray((seg_data * 255).astype(np.uint8))
                            seg_path = os.path.join(self.output_dir, f"seg_{self.data_counter:05d}.png")
                            seg_image.save(seg_path)
                    except:
                        pass  # Segmentation may not be available in all setups
                
                self.data_counter += 1
                
                if i % 10 == 0:
                    print(f"Generated {i+1}/{num_samples} samples")
        
        print(f"Synthetic data generation complete. Total samples: {self.data_counter}")

    def randomize_scene(self):
        """Randomize scene parameters for domain randomization"""
        # Randomize lighting conditions
        dome_light = get_prim_at_path("/World/DomeLight")
        if dome_light:
            # Randomize dome light color and intensity
            intensity = np.random.uniform(500, 1500)
            dome_light.GetAttribute("inputs:intensity").Set(intensity)
            
            # Randomize color slightly
            color = [np.random.uniform(0.8, 1.0), np.random.uniform(0.8, 1.0), np.random.uniform(0.9, 1.0)]
            dome_light.GetAttribute("inputs:color").Set(color)
        
        # Randomize object positions slightly
        for i in range(5):
            prim_path = f"/World/cube_{i}"
            prim = get_prim_at_path(prim_path)
            if prim:
                # Add small random offset to position
                current_pos = self.world.scene._physics_context.get_rigid_body_position(f"cube_{i}")
                new_pos = [
                    current_pos[0] + np.random.uniform(-0.1, 0.1),
                    current_pos[1] + np.random.uniform(-0.1, 0.1),
                    current_pos[2]
                ]

def main():
    # Initialize Isaac Sim application context
    omni.kit.examples.show_simpler_extensions_window()
    
    # Create synthetic data generator
    generator = SyntheticDataGenerator()
    
    # Generate synthetic data
    generator.generate_synthetic_data(num_samples=50)
