# Chapter 1: Voice-to-Action - Using OpenAI Whisper for Voice Commands

## Introduction

Voice-to-action systems represent a natural evolution in human-robot interaction, allowing users to control robots through spoken commands that the robot can understand and execute. OpenAI Whisper, a state-of-the-art automatic speech recognition (ASR) system, provides the foundation for converting human speech into text that can be processed by robot control systems. This chapter explores the implementation of Whisper-based voice command systems that enable intuitive voice control of robotic platforms through natural language interaction.

## Explanation

The voice-to-action pipeline involves several stages: audio capture, speech recognition, intent parsing, and action execution. Whisper serves as the critical first stage, converting spoken language into text with high accuracy across multiple languages and speaking conditions. The recognized text is then processed by natural language understanding systems that extract the user's intent and map it to appropriate robot actions, creating a seamless interaction flow from spoken command to robotic response.

### Speech Recognition with Whisper

Whisper excels at voice recognition through:
- **Multilingual Support**: Recognition across numerous languages and dialects
- **Robustness**: Performance in noisy environments and diverse acoustic conditions
- **Real-time Processing**: Capability for streaming audio processing
- **Contextual Understanding**: Improved accuracy with proper prompting

### Audio Processing Pipeline

The voice command system includes:
- **Audio Capture**: Microphone arrays for optimal speech acquisition
- **Noise Reduction**: Filtering to improve speech recognition accuracy
- **Voice Activity Detection**: Automatic detection of speech segments
- **Language Identification**: Determining the language being spoken

### Intent Recognition and Parsing

After speech recognition, the system performs:
- **Command Parsing**: Extracting action verbs and object references
- **Context Understanding**: Interpreting commands within environmental context
- **Ambiguity Resolution**: Handling unclear or ambiguous commands
- **Validation**: Ensuring commands are safe and executable

### Integration with Robot Control

Voice commands connect to:
- **ROS 2 Action Servers**: Asynchronous command execution
- **Navigation Goals**: Waypoint navigation from spoken destinations
- **Manipulation Tasks**: Object interaction from voice descriptions
- **Social Behaviors**: Human-like responses to verbal interactions

## Code Blocks

Here's an example implementation of a Whisper-based voice command system for robot control:

```python title="voice_command_system.py"
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import Twist
from sensor_msgs.msg import AudioData
import speech_recognition as sr
import threading
import queue
import time
from vosk import Model, KaldiRecognizer
import json
import pyaudio

class VoiceCommandSystem(Node):
    def __init__(self):
        super().__init__('voice_command_system')
        
        # Initialize Whisper-based speech recognition
        # Note: Using VOSK as an example, but Whisper can be integrated similarly
        try:
            self.speech_recognizer = sr.Recognizer()
            self.microphone = sr.Microphone()
            
            # Configure for noise reduction
            with self.microphone as source:
                self.speech_recognizer.adjust_for_ambient_noise(source)
            
            self.get_logger().info('Speech recognition initialized')
        except Exception as e:
            self.get_logger().warn(f'Speech recognition initialization failed: {e}')
            self.speech_recognizer = None
        
        # Publisher for robot commands
        self.cmd_vel_pub = self.create_publisher(Twist, '/cmd_vel', 10)
        
        # Publisher for command interpretation
        self.interpretation_pub = self.create_publisher(String, '/voice_interpretation', 10)
        
        # Timer for voice processing
        self.voice_timer = self.create_timer(0.1, self.process_voice_commands)
        
        # State variables
        self.command_queue = queue.Queue()
        self.processing_thread = threading.Thread(target=self.voice_processing_loop, daemon=True)
        self.processing_thread.start()
        
        self.last_command_time = time.time()
        self.voice_active = True
        
        self.get_logger().info('Voice Command System initialized')

    def voice_processing_loop(self):
        """Background thread for continuous voice processing"""
        if self.speech_recognizer is None:
            return
            
        with self.microphone as source:
            while rclpy.ok():
                try:
                    # Listen for audio with timeout
                    audio = self.speech_recognizer.listen(source, timeout=1, phrase_time_limit=5)
                    
                    # Perform speech recognition
                    text = self.speech_recognizer.recognize_google(audio)
                    
                    # Add recognized text to command queue
                    self.command_queue.put(text)
                    
                    self.get_logger().info(f'Recognized: {text}')
                    
                except sr.WaitTimeoutError:
                    # No speech detected, continue listening
                    continue
                except sr.UnknownValueError:
                    self.get_logger().info('Could not understand audio')
                except sr.RequestError as e:
                    self.get_logger().error(f'Speech recognition error: {e}')
                except Exception as e:
                    self.get_logger().error(f'Voice processing error: {e}')

    def process_voice_commands(self):
        """Process recognized voice commands"""
        while not self.command_queue.empty():
            try:
                text = self.command_queue.get_nowait()
                
                # Publish interpretation
                interp_msg = String()
                interp_msg.data = f"Interpreted: {text}"
                self.interpretation_pub.publish(interp_msg)
                
                # Parse and execute command
                self.parse_and_execute_command(text.lower())
                
            except queue.Empty:
                break

    def parse_and_execute_command(self, text):
        """Parse recognized text and execute corresponding robot action"""
        # Normalize the text
        text = text.strip()
        
        # Dictionary of common commands
        command_mappings = {
            'forward': self.move_forward,
            'backward': self.move_backward,
            'back': self.move_backward,
            'left': self.turn_left,
            'right': self.turn_right,
            'stop': self.stop_robot,
            'halt': self.stop_robot,
            'go': self.move_forward,
            'move': self.move_forward,
            'come here': self.move_towards_speaker,
            'turn around': self.turn_around,
            'spin': self.turn_around
        }
        
        # Check for direct command matches
        for command, action in command_mappings.items():
            if command in text:
                self.get_logger().info(f'Executing command: {command}')
                action()
                return
        
        # Check for complex commands with parameters
        if 'go to' in text or 'navigate to' in text:
            self.handle_navigation_command(text)
            return
        elif 'pick up' in text or 'grasp' in text:
            self.handle_manipulation_command(text)
            return
        elif 'follow' in text:
            self.handle_follow_command(text)
            return
        
        # If no command recognized
        self.get_logger().info(f'Command not recognized: {text}')

    def move_forward(self):
        """Move robot forward"""
        cmd = Twist()
        cmd.linear.x = 0.3  # Forward at 0.3 m/s
        cmd.angular.z = 0.0
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Moving forward')

    def move_backward(self):
        """Move robot backward"""
        cmd = Twist()
        cmd.linear.x = -0.2  # Backward at 0.2 m/s
        cmd.angular.z = 0.0
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Moving backward')

    def turn_left(self):
        """Turn robot left"""
        cmd = Twist()
        cmd.linear.x = 0.0
        cmd.angular.z = 0.3  # Turn left at 0.3 rad/s
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Turning left')

    def turn_right(self):
        """Turn robot right"""
        cmd = Twist()
        cmd.linear.x = 0.0
        cmd.angular.z = -0.3  # Turn right at 0.3 rad/s
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Turning right')

    def stop_robot(self):
        """Stop robot movement"""
        cmd = Twist()
        cmd.linear.x = 0.0
        cmd.angular.z = 0.0
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Stopping robot')

    def turn_around(self):
        """Turn robot 180 degrees"""
        cmd = Twist()
        cmd.linear.x = 0.0
        cmd.angular.z = 0.5  # Turn at 0.5 rad/s
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Turning around')
        
        # Stop after half rotation (assuming 0.5 rad/s for 3.14/0.5 = ~6.28s)
        self.timer = self.create_timer(3.14, self.stop_robot)

    def move_towards_speaker(self):
        """Move towards the speaker (simplified as forward movement)"""
        cmd = Twist()
        cmd.linear.x = 0.2  # Move towards speaker
        cmd.angular.z = 0.0
        self.cmd_vel_pub.publish(cmd)
        self.get_logger().info('Moving towards speaker')

    def handle_navigation_command(self, text):
        """Handle navigation commands like 'go to kitchen'"""
        if 'kitchen' in text:
            self.get_logger().info('Navigating to kitchen')
            # In a real system, this would call navigation2
            # self.navigate_to_location('kitchen')
        elif 'living room' in text:
            self.get_logger().info('Navigating to living room')
        elif 'bedroom' in text:
            self.get_logger().info('Navigating to bedroom')
        elif 'office' in text:
            self.get_logger().info('Navigating to office')
        else:
            self.get_logger().info(f'Unknown navigation destination: {text}')
        
        # For now, just move forward as a placeholder
        self.move_forward()

    def handle_manipulation_command(self, text):
        """Handle manipulation commands like 'pick up red ball'"""
        self.get_logger().info(f'Manipulation command: {text}')
        # In a real system, this would interface with manipulation stack
        # For now, just stop robot as a placeholder
        self.stop_robot()

    def handle_follow_command(self, text):
        """Handle follow commands"""
        self.get_logger().info(f'Following command: {text}')
        # In a real system, this would activate person following behavior
        self.move_forward()

def main(args=None):
    rclpy.init(args=args)
    
    voice_system = VoiceCommandSystem()
    
    try:
        rclpy.spin(voice_system)
    except KeyboardInterrupt:
        pass
    finally:
        voice_system.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Conclusion

Voice-to-action systems using advanced speech recognition technologies like OpenAI Whisper enable intuitive human-robot interaction that significantly lowers the barrier to robot operation. By converting natural spoken language into executable robot commands, these systems make robotic platforms accessible to non-technical users while providing a natural interaction modality that feels intuitive and efficient. The integration of robust speech recognition with robot control systems creates flexible, responsive robots that can adapt to changing user needs through simple verbal commands. As these technologies continue to advance, voice control will become an increasingly important aspect of human-robot collaboration in diverse application domains.
