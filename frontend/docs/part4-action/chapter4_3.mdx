# Chapter 2: Cognitive Planning - Using LLMs to Translate Natural Language into ROS 2 Actions

## Introduction

Language models have revolutionized the field of natural language processing, offering unprecedented capabilities for understanding and generating human language. In robotics, Large Language Models (LLMs) serve as sophisticated cognitive planners that can interpret natural language instructions and generate appropriate sequences of robotic actions. This chapter explores the integration of LLMs with ROS 2 systems, creating cognitive agents that can understand high-level human commands and translate them into executable robotic behaviors.

## Explanation

The cognitive planning process bridges human intent and robotic action through several key stages: natural language understanding, action decomposition, sequence planning, and execution validation. LLMs excel at this task due to their ability to understand context, reason about spatial relationships, and generate structured outputs. When combined with ROS 2's action-based architecture, LLMs can generate sequences of ROS actions that achieve complex behavioral goals specified in natural language.

### Natural Language Understanding

LLMs in robotic systems must:
- **Interpret Commands**: Parse natural language instructions into structured intents
- **Recognize Objects**: Identify objects and locations mentioned in commands
- **Understand Context**: Consider environmental context and robot capabilities
- **Handle Ambiguity**: Resolve unclear or ambiguous instructions

### Action Mapping and Decomposition

The planning process involves:
- **Primitive Identification**: Mapping high-level commands to primitive actions
- **Sequence Generation**: Creating ordered sequences of actions
- **Constraint Checking**: Verifying physical and safety constraints
- **Context Integration**: Incorporating environmental and sensor information

### LLM Integration with ROS 2

Successful integration requires:
- **Action Schema Knowledge**: Understanding available ROS 2 actions
- **Service Calls**: Invoking appropriate ROS services
- **Topic Mapping**: Connecting language concepts to ROS topics
- **Feedback Integration**: Incorporating execution feedback

### Prompt Engineering for Robotics

Effective robotics prompts include:
- **Robot Capabilities**: Clear specification of available actions
- **Environment Context**: Information about current robot state and surroundings
- **Safety Constraints**: Explicit safety and operational limits
- **Action Sequences**: Structured format for generated action plans

    def command_callback(self, msg):
        """Process natural language command"""
        command = msg.data
        self.get_logger().info(f'Received command: {command}')
        
        # Publish status
        status_msg = String()
        status_msg.data = f'Processing command: {command}'

        # Generate action plan using LLM
        action_plan = self.generate_action_plan(command)
        
        if action_plan:
            # Publish action plan
            plan_msg = String()
            plan_msg.data = json.dumps(action_plan)
            self.action_plan_pub.publish(plan_msg)
            
            # Execute the action plan
            self.execute_action_plan(action_plan)
        else:
            self.get_logger().error('Failed to generate action plan')

    def generate_action_plan(self, command):
        """Generate action plan using LLM"""
        # In a real implementation, this would call an LLM API
        # For demonstration, we'll use rule-based parsing
        
        try:
            # Create prompt for LLM to generate structured action plan

            return action_plan

            self.get_logger().error(f'Error generating action plan: {e}')

    def create_planning_prompt(self, command):
        """Create prompt for LLM-based planning"""
        prompt = f"""
        You are a robot cognitive planner. Convert the following natural language command into a sequence of robotic actions.
        
        Available actions:
        {json.dumps(self.available_actions, indent=2)}
        
        Known locations:
        {json.dumps(self.location_map, indent=2)}
        
        Known objects and their locations:
        {json.dumps(self.object_locations, indent=2)}
        
        Current robot position: {json.dumps(self.current_position)}
        
        Natural language command: "{command}"
        
        Respond with a JSON object containing an "actions" array. Each action should have:
        - "action_type": The type of action (from available actions)
        - "parameters": The required parameters for the action
        
        Example response format:
        {{
            "actions": [
                {{
                    "action_type": "NAVIGATE_TO",
                    "parameters": {{"x": 1.0, "y": 2.0, "frame_id": "map"}}
                }},
                {{
                    "action_type": "PICK_UP_OBJECT",
                    "parameters": {{"object_name": "red_ball", "object_position": {{"x": 1.0, "y": 2.0}}}}
                }}
            ]
        }}
        
        Respond only with the JSON object, nothing else:
        """

    def mock_llm_response(self, command):
        """Mock implementation of LLM response"""
        # This would be replaced with actual LLM call
        command_lower = command.lower()
        
        if 'go to' in command_lower or 'navigate to' in command_lower:
            for location, coords in self.location_map.items():
                if location in command_lower:
                    return json.dumps({
                        "actions": [
                            {

                                "parameters": {"x": coords["x"], "y": coords["y"], "frame_id": "map"}
                            }
                        ]
                    })

            for obj_name, coords in self.object_locations.items():
                if obj_name in command_lower:
                    return json.dumps({
                        "actions": [
                            {
                                "action_type": "NAVIGATE_TO",
                                "parameters": {"x": coords["x"], "y": coords["y"], "frame_id": "map"}
                            },
                            {
                                "action_type": "PICK_UP_OBJECT",
                                "parameters": {"object_name": obj_name, "object_position": coords}
                            }
                        ]
                    })
        elif 'follow' in command_lower:
            return json.dumps({
                "actions": [
                    {
                        "action_type": "FOLLOW_PERSON",
                        "parameters": {"person_identifier": "tracked_person"}
                    }
                ]
            })
        elif 'speak' in command_lower or 'say' in command_lower:
            # Extract message from command
            if 'say' in command_lower:
                message_start = command_lower.find('say') + 3
            else:
                message_start = command_lower.find('speak') + 5
            
            message = command[message_start:].strip().strip('"\'')
            return json.dumps({
                "actions": [
                    {
                        "action_type": "SPEAK",
                        "parameters": {"message": message}
                    }
                ]
            })
        
        # Default response for unrecognized commands
        return json.dumps({
            "actions": [
                {
                    "action_type": "SPEAK",
                    "parameters": {"message": f"I don't understand the command: {command}"}
                }
            ]
        })

    def execute_action_plan(self, action_plan):
        """Execute the generated action plan"""
        for action in action_plan.get('actions', []):
            action_type = action.get('action_type')
            parameters = action.get('parameters', {})
            
            self.get_logger().info(f'Executing action: {action_type} with parameters: {parameters}')
            
            if action_type == "NAVIGATE_TO":
                self.execute_navigate_to(parameters)
            elif action_type == "PICK_UP_OBJECT":
                self.execute_pick_up_object(parameters)
            elif action_type == "PLACE_OBJECT":
                self.execute_place_object(parameters)
            elif action_type == "FOLLOW_PERSON":
                self.execute_follow_person(parameters)
            elif action_type == "SPEAK":
                self.execute_speak(parameters)
            elif action_type == "SEARCH_FOR_OBJECT":
                self.execute_search_for_object(parameters)
            else:
                self.get_logger().warn(f'Unknown action type: {action_type}')

    def execute_navigate_to(self, parameters):
        """Execute navigation action"""
        x = parameters.get('x', 0.0)
        y = parameters.get('y', 0.0)
        frame_id = parameters.get('frame_id', 'map')
        
        self.get_logger().info(f'Navigating to ({x}, {y}) in frame {frame_id}')
        
        # Wait for action server
        if not self.nav_client.wait_for_server(timeout_sec=5.0):
            self.get_logger().error('Navigation server not available')
            return
        
        # Create navigation goal
        goal_msg = NavigateToPose.Goal()
        goal_msg.pose.header.frame_id = frame_id
        goal_msg.pose.pose.position.x = x
        goal_msg.pose.pose.position.y = y
        goal_msg.pose.pose.position.z = 0.0
        goal_msg.pose.pose.orientation.w = 1.0  # No rotation
        
        # Send navigation goal
        self.nav_client.send_goal_async(goal_msg)

## Conclusion

The integration of Large Language Models with ROS 2 systems creates powerful cognitive planners that can interpret natural language instructions and execute them as robotic behaviors. This approach represents a significant step toward truly autonomous robots that can understand and respond to human commands in natural language. By combining the language understanding capabilities of LLMs with the execution framework of ROS 2, developers can create robots that perform complex tasks based on high-level human instructions without requiring detailed programming for each specific scenario. This cognitive planning approach is particularly valuable for humanoid robots that need to operate in human environments where natural communication is expected and preferred.
